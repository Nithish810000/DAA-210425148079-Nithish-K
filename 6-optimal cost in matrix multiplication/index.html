METHOD / 08 THE RECURRENCE

From brute force to a table.

Longer chains depend only on shorter chains, so we solve by increasing chain length.

CORE RECURRENCE
m[i, j] = min i ≤ k < j { m[i, k] + m[k+1, j] + pi−1pkpj }

The first two terms reuse solved subchains. The last term is the cost of multiplying their resulting matrices.

  1. 01
    Initialize the diagonal

    A single matrix needs zero multiplications, so m[i, i] = 0.

  2. 02
    Grow the chain length

    Solve chains of length 2, then 3, continuing to the full chain.

  3. 03
    Try every split k

    Combine the best left and right costs with the final multiplication cost.

  4. 04
    Keep the minimum

    Store its cost in m and its split position in s for reconstruction.

TIMEO(n³)

Chain length × starting index × split position.

SPACEO(n²)

Two triangular n × n tables for costs and splits.

PROPERTYOptimal

Every chosen subchain must itself have the lowest possible cost.

def matrix_chain_order(dims):
    """Matrix Chain Multiplication using dynamic programming."""
    n = len(dims) - 1
    # m[i][j] = minimum multiplications for matrices i..j
    m = [[0] * (n + 1) for _ in range(n + 1)]
    s = [[0] * (n + 1) for _ in range(n + 1)]

    # l is the chain length
    for l in range(2, n + 1):
        for i in range(1, n - l + 2):
            j = i + l - 1
            m[i][j] = float('inf')

            for k in range(i, j):
                cost = (
                    m[i][k]
                    + m[k + 1][j]
                    + dims[i - 1] * dims[k] * dims[j]
                )
                if cost < m[i][j]:
                    m[i][j] = cost
                    s[i][j] = k

    return m, s


def optimal_parens(s, i, j):
    if i == j:
        return f'A{i}'
    k = s[i][j]
    left = optimal_parens(s, i, k)
    right = optimal_parens(s, k + 1, j)
    return f'({left} x {right})'


dims = [10, 30, 5, 60, 10]
m, s = matrix_chain_order(dims)
n = len(dims) - 1
print('Minimum:', m[1][n])
print('Order:', optimal_parens(s, 1, n))
